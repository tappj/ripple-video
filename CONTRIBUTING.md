# Contributing

Thanks for helping improve Ripple.

1. Open an issue before a large change so the approach can be discussed.
2. Create a focused branch and include tests for behavior changes.
3. Run `pytest`, `ruff check .`, and `mypy cutdetect` before opening a pull request.
4. Keep pull requests small and explain the user-visible result.

Do not commit API keys, `.env` files, generated outputs, personal media, provider logs, or test
fixtures without clear redistribution rights. Use synthetic or self-created fixtures, keep them as
small as possible, and document their license. By contributing, you agree that your contribution is
licensed under the repository's MIT License.
