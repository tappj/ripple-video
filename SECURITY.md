# Security policy

Please report vulnerabilities privately through GitHub's **Security → Report a vulnerability**
feature. Do not open a public issue with credentials, private media, exploit details, or provider
responses.

Before sharing a report, remove uploaded media, API keys, cookies, local paths, and task identifiers
from screenshots and logs. If a credential may have been exposed, revoke it at the provider first;
removing it from the latest commit is not enough because Git history and forks may retain it.

Only the latest release is supported with security fixes. This project is provided without a
warranty; hosted operators are responsible for authentication, rate limits, spending controls,
data retention, and compliance with applicable privacy laws and provider terms.
